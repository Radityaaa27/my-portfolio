### Cosmos Explorer — Currently Building

An educational astronomy web experience I'm building because I've always been interested in astronomy and wanted to turn that interest into something people can actually learn from — not just another space-themed website.

The project prioritizes:

- Experience over features
- Scientific accuracy over visual gimmicks
- Learning value over data quantity
